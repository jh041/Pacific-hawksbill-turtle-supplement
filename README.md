This directory contains the supplement for the paper, Cryptic diversity in a critically endangered sea turtle and the importance of genetic context in marine conservation

Here you will find all my notes for the methods I used in the paper, plus the primer input files for MegaSat (https://github.com/beiko-lab/MEGASAT/tree/master), and the filtered genotypes from the study.

Raw fastq sequences for the samples can be found on NCBI under BioProject PRJNA1492081
